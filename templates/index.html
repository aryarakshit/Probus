We pay hackers to prove the AI wrong.

Translator miners turn legacy C into #![forbid(unsafe_code)] Rust. Breaker miners are paid to find the one input where the two programs disagree. Validators compile both under sanitizers, compare every byte of stdout and every exit code, and commit the verdict — with the reproducer — to a merkle-chained ledger. The output is not a translation; it is a translation nobody could break.

01

Translate

LLM miner drafts Safe Rust, compiles it, fuzzes it against the C oracle itself, and repairs from the evidence before submitting.

02

Break

Breaker compiles the candidate, mutates inputs against the C reference until stdout or exit code diverge, then shrinks the reproducer.

03

Verify

Static gate <1 ms → rustc -F unsafe_code → sandboxed differential run → cubed pass-rate, 50% anti-collusion bounty, ledger commit.

§1Translator score

                
pre_t = (passed / total)³

                
Gate fail, rustc fail or >64 KB source → 0. Cubing makes 90% correct worth 0.73 and 50% worth 0.125: partial translations are not a business.

            

            

                
§2Breaker bounty

                
bounty = 0.5 · pre_t / |B_t|

                
A broken translator's score becomes 0 and half of what it would have earned is split among the breakers that broke it. Planting a bug and "finding" it with a second hotkey nets −0.5·pre_t. Collusion loses money.

            

            

                
§3Valid input

                
ASan+UBSan clean · no crash · no timeout

                
Every breaker input first runs on the sanitizer build of the C reference. UB farming is rejected and penalised (−0.05 each). Non-zero exit codes are legitimate behaviour and must be matched.

            

            

                
§4Sandbox

                
--network none · --read-only · --cap-drop ALL · 256 MB · 1 CPU · uid 65534

                
Candidates compile and run in a throwaway container (or the host toolchain in dev). stdout bytes and exit codes are compared; nothing else is trusted.
